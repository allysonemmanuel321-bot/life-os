Sincronização Simultânea (PC & Celular)

Conecte seu banco na nuvem para atualizar suas finanças ao mesmo tempo no computador e no celular.

1. Sincronização em Tempo Real (Firebase) Apenas Local

Com a sincronização ativa, qualquer lançamento financeiro registrado no PC aparece automaticamente em segundos no celular (e vice-versa).

2. Como Abrir Simultâneo no Celular Pareamento Rápido
Passo 1 (Criar Banco Grátis — 1 min): Acesse console.firebase.google.com → Criar Projeto → menu Realtime Database → Criar banco de dados (modo de teste) e copie a URL gerada (ex: https://...-rtdb.firebaseio.com).
Passo 2 (Abrir no Celular): Você pode hospedar este arquivo .html gratuitamente no Netlify Drop (app.netlify.com/drop) ou GitHub Pages, ou abrir o arquivo no navegador do celular e colar o código de pareamento abaixo:
QR Code do Link Sincronizado Se o seu aplicativo estiver hospedado online, basta apontar a câmera do celular para abrir já conectado na mesma conta!
